# RFID Unlock — инструкция пользователя

Разблокировка и блокировка ПК на Ubuntu смартфоном Android через NFC-метку.
Положили телефон на метку — ПК разблокировался; взяли телефон (или сняли с
зарядной подставки) — заблокировался.

Состав: **агент на ПК** (сервер + иконка в трее с QR-кодом) и
**приложение на Android**.

---

## 1. Что нужно

| | Требование |
|---|---|
| ПК | Ubuntu с GNOME (X11 или Wayland) |
| Смартфон | Android 10+, NFC, arm64 |
| Метка | любая NFC-метка (стикер, брелок) |
| Вне домашней сети | ПК в сети ZeroTier (см. п. 3) |

Из домашней Wi-Fi всё работает и без ZeroTier.

---

## 2. Установка агента на ПК

```bash
cd ubuntu-agent
./install-server.sh
```

Скрипт:
- ставит сервер и трей в `~/.local/bin`, создаёт токен в
  `~/.config/rfid-agent/token`;
- включает user-сервис `rfid-server.service` (стартует при входе в систему);
- добавляет трей в автозапуск и запускает его;
- если ПК уже в ZeroTier — сам подхватывает параметры сети для QR
  (`zt-network`, `zt-moon`, `zt-roots`).

Проверка: `systemctl --user status rfid-server.service` → `active (running)`.

Иконка в трее на GNOME требует расширение AppIndicator:
`sudo apt install gnome-shell-extension-appindicator`, включить
«Ubuntu AppIndicators», перелогиниться.

Повторный запуск `./install-server.sh` обновляет агент; токен сохраняется,
переподключать телефон не нужно.

---

## 3. ZeroTier (для работы вне домашней сети)

1. Вступите ПК в сеть: `sudo zerotier-cli join <network id>`; авторизуйте ПК
   на контроллере сети.
2. Запустите (или перезапустите) `./install-server.sh` — файлы
   `~/.config/rfid-agent/zt-*` создадутся автоматически. Если ZeroTier
   установлен нестандартно — создайте вручную (таблица в README).
3. **Перезапустите трей** после появления zt-файлов, иначе QR останется без
   параметров сети (профиль на телефоне будет показывать «Недоступен»).
4. После первого сканирования QR на телефоне появится **узел приложения** —
   его нужно **авторизовать** на контроллере сети. Node ID: приложение →
   Настройки → «Встроенный ZeroTier» (появляется после первой команды).

Приложение ZeroTier на телефоне не требуется: узел встроен в приложение и
не занимает VPN-слот Android. Если пользуетесь другим VPN (Hiddify и т.п.) —
добавьте RFID Unlock в его исключения (split-tunnel).

## 5. Первая настройка

### 5.1 Добавить ПК
1. На ПК: иконка в трее → **«Показать QR-код»**.
2. В приложении: **«Добавить ПК (QR)»** → навести камеру.
3. ПК появится плиткой на экране **«Мои ПК»**. Нажмите **«Обновить статусы»** —
   плитка должна стать зелёной («Разблокирован») или красной («Заблокирован»).

QR содержит токен доступа — показывайте его только своим устройствам.

### 5.2 Добавить метку
1. Откройте экран **«Метки RFID»**.
2. Поднесите телефон к метке → диалог **«Новая метка»** → задайте имя →
   «Сохранить».
3. У метки выберите:
   - **Привязка к ПК** — конкретный ПК или **«Универсальная (любой ПК)»**
     (открывает экран плиток, команд не шлёт).
   - **Логика срабатывания**:
     - **Присутствие** — положили телефон на метку → UNLOCK, убрали → LOCK
       (рекомендуется для подставки/дока на столе);
     - **Переключение** — каждое касание меняет состояние: LOCK ↔ UNLOCK
       (для брелока-метки).

Метку можно переименовать («Изменить имя»), выключить или удалить.

### 5.3 Плитки в шторке (по желанию)
1. Шторка быстрых настроек → «Изменить» → перетащите плитку **«RFID ПК 1»**
   (доступно 4 слота: ПК 1…4).
2. Тап по ненастроенной плитке (или долгое нажатие) → выберите ПК.
3. Дальше тап по плитке — переключение LOCK/UNLOCK без открытия приложения.
   Плитка подсвечена = ПК разблокирован.

## 6. Ежедневное использование

| Действие | Результат |
|---|---|
| Положить телефон на метку («Присутствие») | ПК разблокирован |
| Взять телефон с метки | ПК заблокирован (детектор движения + проверка метки) |
| Снять телефон с зарядки (Type-C док) | ПК заблокирован — работает и без метки |
| Коснуться метки («Переключение») | LOCK ↔ UNLOCK по очереди |
| Тап по плитке ПК в приложении | LOCK ↔ UNLOCK |
| Долгое нажатие на плитку | «Сведения» (адрес, ОС) / «Удалить ПК» |
| Тап по плитке в шторке | LOCK ↔ UNLOCK |

Приложение должно быть запущено (в фоне) для работы NFC и датчика зарядки —
оно держит foreground-сервис с уведомлением. Не убивайте его «очисткой памяти»;
на OnePlus/Oppo снимите ограничения батареи для RFID Unlock.

**Скорость.** В домашней сети команда выполняется мгновенно. Вне сети первая
команда после долгого простоя занимает до ~40 с (старт встроенного узла и обход
NAT), следующие 5 минут — мгновенно.

## 7. Если что-то не работает

| Симптом | Причина → что делать |
|---|---|
| Плитка «Недоступен» дома | Сервер не запущен: `systemctl --user restart rfid-server.service`. Телефон в другой Wi-Fi/гостевой сети. |
| «Недоступен» дома, ПК даёт ZT-адрес (10.x) | На ПК не было zt-файлов при показе QR → выполнить п. 3 (шаги 2–3) и **заново отсканировать QR** (старый профиль удалить долгим нажатием). |
| «Недоступен» вне дома | Узел приложения не авторизован на контроллере ZeroTier (п. 3.4). VPN на телефоне перехватывает трафик — добавить приложение в исключения. |
| Команда идёт, ответ «Ошибка: unauthorized» | Токен на ПК изменился (например, удалён `~/.config/rfid-agent/token`) → пересканировать QR. Или расходятся часы ПК/телефона более чем на 5 минут. |
| LOCK не срабатывает при снятии | У метки режим «Переключение» — LOCK по снятию работает только в «Присутствии». Приложение убито системой — снять ограничения батареи. |
| Нет иконки в трее | Нет AppIndicator (п. 2) или трей не запущен: `~/.local/share/rfid-agent/venv/bin/python ~/.local/bin/rfid-tray.py &` |
| Метка не читается | Включить NFC в системных настройках; на метке нет ограничений — читается только UID. |

Журнал сервера: `~/.local/state/rfid-agent/rfid-server.log` — видно каждое
соединение (адрес телефона) и причину отказа (`missing-auth`, `bad-ts`,
`stale-ts`, `replay`, `bad-signature`).

Проверка связи вручную: Настройки → «Ручное подключение (резерв)» → ввести
IP/порт/токен → **«Проверить связь»** (ожидается «Связь с ПК: OK»).

## 8. Безопасность коротко

- Токен по сети не передаётся: команды подписаны HMAC-SHA256, повторы
  отбрасываются (окно ±5 мин + одноразовый reqId).
- Вне LAN трафик дополнительно шифруется ZeroTier.
- Скомпрометирован телефон — удалите `~/.config/rfid-agent/token` на ПК,
  запустите `./install-server.sh` (создаст новый токен) и пересканируйте QR на
  доверенных устройствах.
